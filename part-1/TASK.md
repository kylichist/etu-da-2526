# Задание

Вариант 1.4

```text
Разработайте параллельный алгоритм умножения двух матриц n*n для P процессов так, чтобы параллельно вычислялись строки результирующей матрицы. 
Исходные матрицы загружены на процессы заранее. 
Сформулировать свойства алгоритма на языке LTL. 
Обмен данными, если он необходим, осуществляется с помощью каналов.
По завершении умножения 0-й процесс выводит результат.
```
