# etu-da-2526 -- ИДЗ #2

Алгоритм Барца: симуляция обобщённого семафора с помощью двух бинарных
семафоров для управления доступом процессов в критическую секцию
(M. Ben-Ari, алгоритм 6.13, стр. 126-129).

## Пререквизиты

1. Установка пакетов: `spin tcl tk graphviz wish`
2. Установка gui-скрипта: [raw](https://raw.githubusercontent.com/nimble-code/Spin/refs/heads/master/optional_gui/ispin.tcl)

Для Ubuntu можно запустить таргет `prerequisites`:

```bash
make prerequisites
```

## Модель

- `S` -- бинарный семафор, взаимное исключение при доступе к `count`.
- `gate` -- бинарный семафор, блокировка/разблокировка процессов на входе.
- `count` -- целочисленный компонент симулируемого обобщённого семафора
  (начальное значение `K`).
- `N` процессов в бесконечном цикле входят в критическую секцию.

Проверяемые свойства LTL:

- `mutex` -- безопасность: в критической секции одновременно не более `K`
  процессов.
- `bingate` -- безопасность: семафор `gate` остаётся бинарным (`[]bingate`).
- `binsem` -- безопасность: семафор `S` остаётся бинарным.
- `liveness` -- живость: критическая секция посещается бесконечно часто.

## Запуск верификации

